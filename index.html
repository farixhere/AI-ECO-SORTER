02 / WHY IT MATTERS

Better sorting
starts with awareness.

Waste segregation helps keep useful materials in circulation and makes responsible disposal easier. AI Eco Sorter is a small learning project that demonstrates one way image classification can support that awareness.

♻️ Reduce mixing

Recognising broad waste groups can encourage people to separate items before disposal.

🌿 Support better habits

Simple visual guidance can make waste segregation easier to learn and practise.

🧠 Explore practical AI

The project shows how a model trained on example images can make predictions about new images.

03 / THE PROCESS

From image
to insight.

The project uses a machine-learning image model trained with Google Teachable Machine. It is a learning prototype, not an automated industrial sorting system.

STEP 01

Show an item

Use the camera or provide an image to the model.

STEP 02

Analyse patterns

The trained model processes visual patterns in the image.

STEP 03

Predict a class

The model estimates which learned category best matches the image.

STEP 04

Learn & sort

Use the result as a starting point for responsible waste handling.

04 / WHAT IT EXPLORES

Three waste
categories.

These are the broad classes used to explain the project's intended waste groups. Always check local collection rules for final disposal decisions.

🌱

Organic / Biodegradable

Organic materials that can naturally break down under suitable conditions.

Examples: fruit and vegetable scraps, leaves, food leftovers.
♻️

Recyclable

Materials that may be processed and made into useful products again.

Examples: paper, cardboard, and accepted plastic or metal containers.
🗑️

Non-recyclable

Items that may not be accepted in common recycling streams.

Examples: certain contaminated or mixed-material items.
🌏
05 / ABOUT THE PROJECT

A small project
with a useful idea.

AI Eco Sorter was created to explore the practical side of machine learning through a familiar everyday challenge: understanding where waste belongs. The project combines image classification with environmental awareness and makes the model available for people to try.

Its predictions are not guaranteed to be correct. Lighting, camera angle, image quality, and differences from training examples can affect results. Please treat it as an educational demonstration.
